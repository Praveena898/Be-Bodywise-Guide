# BloomWise

An independent product guide that helps people choose between Be Bodywise products and set realistic expectations.
It is not the official Be Bodywise website.

## Features
- Find my fit: a short guided flow with safety flags
- Product pages: ingredients in plain language, directions, realistic expectations, sources
- My plan: daily checklist, 90-day review window, weekly check-ins, shareable summary
- Help: FAQs

## Tech
React 18, Vite, Tailwind CSS 3, htm. Data is saved in the browser's localStorage.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build   # outputs to dist/
```

## Deploy
Import the repo in Vercel. It detects Vite automatically (build: `npm run build`, output: `dist`).

Product details were compiled from public listings on 25 Nov 2026 and may change. Always check the product pack.
